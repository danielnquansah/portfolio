# Evaluation Methods

## Overview

Evaluation provides systematic evidence on the relevance, effectiveness, efficiency, sustainability, and impact of programmes and policies.

---

## Evaluation Approaches

### Process Evaluation

Examines whether programme activities were implemented as intended.

### Outcome Evaluation

Examines whether the intervention produced measurable changes among beneficiaries.

### Impact Evaluation

Assesses whether observed changes can reasonably be attributed to an intervention.

### Mixed-Methods Evaluation

Combines quantitative and qualitative evidence to provide a more comprehensive understanding of programme performance.

---

## Quantitative Methods

- Descriptive statistics
- Cross-tabulation
- Regression analysis
- Experimental methods
- Quasi-experimental methods
- Difference-in-differences
- Matching approaches

---

## Qualitative Methods

- Key informant interviews
- Focus group discussions
- Stakeholder consultations
- Document review
- Thematic analysis

---

## Data Quality

Evaluation findings depend heavily on the quality of the underlying data.

Key quality dimensions include:

- Accuracy
- Completeness
- Consistency
- Timeliness
- Validity
- Reliability
