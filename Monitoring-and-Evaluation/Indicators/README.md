# Monitoring Indicators

## Overview

Indicators provide measurable evidence for assessing whether programme activities and interventions are progressing as planned.

---

## Types of Indicators

### Input Indicators

Measure resources invested in an intervention.

Examples:

- Programme budget
- Number of staff
- Number of training materials

### Process Indicators

Measure implementation activities.

Examples:

- Number of training sessions conducted
- Number of communities visited
- Number of beneficiaries reached

### Output Indicators

Measure immediate deliverables.

Examples:

- Number of participants trained
- Number of households surveyed
- Number of businesses supported

### Outcome Indicators

Measure changes resulting from programme outputs.

Examples:

- Adoption of digital financial services
- Increased knowledge
- Increased business activity

### Impact Indicators

Measure longer-term changes.

Examples:

- Improved household welfare
- Increased financial inclusion
- Improved economic resilience

---

## Indicator Quality

Good indicators should be:

- Specific
- Measurable
- Achievable
- Relevant
- Time-bound

They should also have:

- Baseline values
- Targets
- Data sources
- Collection frequency
- Responsible persons
